# ⚙️ JustBus Backend – Smart Transportation System API

JustBus Backend is the core server-side infrastructure powering the JustBus transportation ecosystem. The backend is responsible for handling authentication, business logic, database operations, real-time trip management, booking workflows, wallet transactions, QR validation, emergency services, and communication between all mobile and web applications.

The system was developed using Node.js and Express.js with a scalable RESTful API architecture and MySQL relational database management.
